# ❤️ Cardiovascular Disease Prediction Using Deep Learning

This project is an AI-based healthcare application developed to predict cardiovascular disease using Deep Learning techniques. The system uses both clinical patient data and medical image analysis to identify the likelihood of heart disease. The application is built using Python, TensorFlow, Streamlit, and various data science libraries to provide real-time prediction, visualization, and analysis.

## 🚀 Features

* Predicts cardiovascular disease using clinical/tabular data
* Medical image-based heart disease prediction using CNN
* Interactive Streamlit web application
* Real-time prediction with confidence score
* Data visualization and analysis dashboard
* Correlation heatmap and feature importance analysis
* Confusion matrix, ROC curve, and accuracy evaluation
* User-friendly interface for healthcare analysis

## 🧠 Technologies Used
